# Expense Tracker 💰

A simple Expense Tracker web application built using HTML, CSS, and JavaScript.

## Features

- Add income
- Add expenses
- Select transaction category
- View total income
- View total expenses
- View current balance
- Delete transactions
- Data persists using localStorage
- Responsive design
- Indian Rupee (₹) currency format

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
